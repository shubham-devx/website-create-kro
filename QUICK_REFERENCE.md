# 🎯 Portfolio Bnao - Quick Reference Guide

## What is Portfolio Bnao?

**Portfolio Bnao** is a completely **free**, **secure**, and **browser-based** portfolio builder that lets anyone create a professional portfolio in minutes without coding.

---

## 🚀 Quick Start (30 Seconds)

1. **Open** `index.html` in your browser
2. **Fill** in your professional details in the left form
3. **Watch** your portfolio appear in real-time on the right
4. **Customize** colors and fonts to your style
5. **Click** "Download My Portfolio" to save
6. **Share** your portfolio.html file anywhere!

## 🆘 Troubleshooting

### Photo won't upload?
- Check file format (JPEG, PNG, or WebP only)
- Check file size (max 8MB)
- Try refreshing the page

### Form not saving?
- Check browser storage limits (5MB max total)
- Try clearing browser cache
- Use incognito/private mode
- Try different browser

### Preview not updating?
- Try refreshing the page
- Check browser console for errors
- Make sure JavaScript is enabled
- Try different browser

### Can't download?
- Check file format (HTML file)
- Try different browser
- Check if JavaScript is enabled
- Check downloads folder

### Lost my draft?
- Check if you cleared browser data
- Check browser storage quota
- Try loading in same browser
- Look for backup HTML files
